# code50-184420526
CS50's Introduction to Artificial Intelligence with Python  This repository contains my solutions to the problem sets from CS50's Introduction to Artificial Intelligence with Python (CS50 AI), offered by Harvard University. Each project explores a core concept in AI — from search algorithms to neural networks — implemented in Python.

📂 Projects Search Degrees — Finds the shortest path of "degrees of separation" between two actors using Breadth-First Search (BFS). Tic-Tac-Toe — An AI that plays Tic-Tac-Toe optimally using the Minimax algorithm. Knowledge Knights — Solves logic puzzles using propositional logic and model checking. Uncertainty Minesweeper — An AI agent that plays Minesweeper using knowledge-based reasoning and inference. PageRank — Ranks web pages by importance using both the random surfer model and the iterative algorithm. Heredity — Uses Bayesian networks to compute the probability of individuals having a particular genetic trait. Optimization Crossword — Generates crossword puzzles by solving them as a constraint satisfaction problem (CSP). Learning Shopping — Predicts whether online shoppers will complete a purchase using a k-nearest neighbor classifier. Nim — An AI that learns to play Nim optimally through reinforcement learning (Q-learning). Neural Networks Traffic — A convolutional neural network (CNN) that classifies traffic signs using TensorFlow. Language Parser — Parses sentences into their grammatical structure using context-free grammar (CFG) and extracts noun phrase chunks. Attention — Analyzes attention patterns in BERT to predict masked words and visualize self-attention heads. 🛠️ Technologies Used Python 3 TensorFlow NLTK scikit-learn 📚 About the Course

CS50 AI is Harvard University's introduction to artificial intelligence, covering key concepts and techniques including search, knowledge representation, uncertainty, optimization, machine learning, neural networks, and natural language processing.
